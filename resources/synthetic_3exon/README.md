# Synthetic validation dataset for `modulator`

A tiny, fully deterministic, **ground-truth-labelled** dataset + test scripts that
exercise every stage of the modulator pipeline end to end and check that each
feature produces the expected output — including the headline question, *if two
modification sites are co-dependent and two are not, does the pipeline call those
relationships correctly?* (it does).

Everything is generated by `generate_synthetic_data.py` (seeded → byte-reproducible).
Total size ~300 KB.

## Contents

| path | what |
|------|------|
| `generate_synthetic_data.py` | the generator (edit + re-run to change the design) |
| `reference/synthetic_ref.fa` (`.fai`) | synthetic genome: `chrSyn` (15 kb) + `chrSyn2` (12 kb) |
| `reference/synthetic_ref.gtf` | reference annotation (7 genes, 12 transcripts) |
| `bams/{M1..M4,Z1..Z4}.bam` (`.bai`) | 8 samples: 4 `mock` + 4 `zikv`, dRNA-style reads with `MM`/`ML` + `pt:i` tags |
| `samples.tsv` | samplesheet (sample → bam, condition, replicate) |
| `ground_truth/ground_truth.tsv` | machine-readable expectation per feature |
| `GROUND_TRUTH.md` | full design + expected-vs-observed table + notes |
| `run_pipeline.sh` | runs all 15 stages on this dataset |
| `validate_outputs.py` | checks the end-to-end outputs against ground truth (30 assertions) |
| `test_classify_categories.py` | unit-validates all 13 `classify_diffs` structural categories |
| `run_tests.sh` | one entry point: smoke checks + classify unit test + pipeline + validation |

## The gene models

**`chrSyn`** (15 kb):
- **GENE_A** (`+`) — the requested layout: **3 exons × 500 nt, introns × 500 nt**. Two
  isoforms (`A1`=e1e2e3, `A2`=e1e3 exon-skip). Carries the modification /
  co-dependency / SNP / haplotype / condition structure.
- **GENE_B** (`+`) — tandem APA: distal TES (canonical `AATAAA` PAS) vs proximal TES
  (no PAS, A-rich downstream → internal-priming). Tails differ by isoform and condition.
- **GENE_C** (`−`) — minus-strand, validates strand handling.

**`chrSyn2`** (12 kb):
- **GENE_OV1 / GENE_OV2** (`+`) — **overlapping** genes (OV1's last exon overlaps OV2's
  first exon) → exercises the **multigene overlap filter**.
- **GENE_TR** (`+`) — 4 exons; isoforms `TR_L` (e1e2e3e4) / `TR_S` (e1e3e4, cassette skip)
  plus **5′-truncated reads** → exercises the **truncation-aware (`hierarchical_stoich`)**
  read-dropping.
- **GENE_TA** (`+`) — tandem APA **with a differential mod** → real `classify_diffs`
  `TANDEM_APA` call.

## Run it

```bash
cd <repo-root>                                              # the modulator checkout
bash resources/synthetic_3exon/run_tests.sh                # everything (smoke + unit + pipeline + validate)
```

or step by step:

```bash
bash resources/synthetic_3exon/run_pipeline.sh                                  # ~2 min, writes results/
<modulator-env>/bin/python resources/synthetic_3exon/validate_outputs.py \
    --results results --prefix syn3exon                                         # 30 PASS / 0 FAIL
<modulator-env>/bin/python resources/synthetic_3exon/test_classify_categories.py  # 13/13 categories
```

`run_pipeline.sh` runs the local checkout via `PYTHONPATH=src python -m modulator`
using the `modulator` conda env's tools (modkit 0.5.0, samtools). It enables
`genotype`, `hierarchical_stoich`, and the between-condition comparisons, i.e. all
15 stages.

## Calibrating the between-condition test

`between_conditions.ref_df` is dataset-dependent (it absorbs the uncertainty of the
*estimated* replicate dispersion). To pick it, run a within-condition null and read
off the ref_df that keeps the null p<0.05 rate near 0.05:

```bash
<modulator-env>/bin/python workflow/scripts/calibrate_between_conditions.py \
    --zn-long results/aggregate_zn/syn3exon_FILTERED_sites_long.tsv \
    --sample-metadata results/syn3exon_sample_metadata.tsv
```

## Regenerate

```bash
<modulator-env>/bin/python resources/synthetic_3exon/generate_synthetic_data.py \
    --samtools <modulator-env>/bin/samtools
```

See `GROUND_TRUTH.md` for the complete site map and the expected result of every feature.
